# MedSafe-Research

Research on prescription OCR, medication recognition,
and generalization to unseen medication names.

## Research Experiments

### V1 — TrOCR Baseline
Baseline OCR evaluation on RxHandBD medication-word images.

### V2 — Medication-Aware OCR
Vocabulary-aware correction and evaluation.

### V3 — Selective OCR
Selective correction strategies and error analysis.

### V4 — Full-Prescription Recognition
Donut-based structured prescription recognition using
MedOCR, including medication-disjoint evaluation.

## Repository Contents

- `checkpoints/` — lightweight model configurations and training logs
- `experiments/` — experiment configurations, audits, and results
- `research_results/` — comparison reports and analysis

## Research Status

Experiments are ongoing. Some V4 model checkpoints
and prediction artifacts are not currently available.

## Data and Models

Large datasets, prescription images, and model weights
